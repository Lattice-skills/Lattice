# Stave — Brief

## Product

Stave is a modern database client for backend engineers at fast-moving startups who find existing tools (phpMyAdmin, Beekeeper, TablePlus) ugly, slow, or both. It exists to make the boring parts of working with a database — connecting, browsing, querying — feel as considered as the rest of a developer's toolchain.

## Audience

Backend engineers, 25–40, at series A–C startups. They have used DataGrip, TablePlus, and Beekeeper. They are familiar with command-line workflows and appreciate a tool that respects the keyboard. They are the people who would switch to a new tool for a better feel — and they have tried the alternatives. They want something that feels like Linear or Vercel: considered, fast, dense without being cluttered.

## Jobs to be done

1. Connect to a database (Postgres, MySQL, Redis).
2. Browse tables and inspect schemas.
3. Write and run a SQL query.

## Vibe

- Focused
- Dense but not crowded
- Restrained color
- Confident typography
- Like Linear, not like Stripe's marketing site

## Anti-references

- Enterprise-y database tools (DataGrip's chrome, SQL Server Management Studio).
- Cutesy consumer apps with illustrations and playful microcopy.
- "Friendly" productivity tools with rounded corners and pastel accents.
- Generic consumer SaaS with hero CTAs, gradient backgrounds, and emoji.

## Stack

Next.js 14 (App Router) + TypeScript + Tailwind CSS. Detected from `package.json`.

## Direction

**Hybrid: dense product with editorial hero.** The marketing site is a focused, single-accent landing page with editorial weight in the hero (a strong headline, generous whitespace, a product preview). The product UI (when built) will be denser — Linear-style sidebar, table-first layout, restrained color.

Reference sites: Linear (app + marketing), Vercel (dashboard), Datadog.

Tweaks: lighter hero for the marketing page than the product UI. The marketing page is for new visitors; the product UI is for power users. The two should feel related but not identical.
